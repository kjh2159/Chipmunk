The official and unrestricted binary editions are proprietary. The PawnIO
module documentation states that redistribution of the unmodified installer is
allowed and recommends directing users to pawnio.eu when practical:

https://github.com/namazso/PawnIO.Modules/wiki/Using-PawnIO-Modules

Only the digitally signed official edition is bundled. Chipmunk
does not install or offer the unrestricted edition.

Installing PawnIO adds a kernel driver and requires explicit user consent plus
Windows UAC administrator approval. Declining installation leaves the
application functional; sensors requiring low-level access remain `N/A`.
